Privacy Policy

Code Professor Uploader · Last updated: November 10, 2026

Code Professor Uploader ("the tool") is a private tool used only by the owner of The Code Professor YouTube channel to publish that channel's own videos. It has no other users.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the channel owner's permission (Google OAuth, scope https://www.googleapis.com/auth/youtube), the tool accesses the owner's YouTube channel in order to:

  • upload the owner's own video files and thumbnail images;
  • set video titles, descriptions, tags, categories, privacy and scheduled publish times;
  • create playlists and add the owner's videos to them;
  • read the channel's own video and playlist lists to avoid duplicates.

It does not access any other user's data, comments, viewer information, analytics, or any data outside the owner's channel.

How data is used and stored

Data is used only to perform the publishing actions above. OAuth credentials are kept in the owner's private environment and are never shared. The tool keeps no database of user data, does not sell or transfer data to anyone, and does not use data for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at Google security settings (third-party access). After revocation the tool can no longer access the channel.
