Privacy Policy

Code Professor Uploader · Last updated: November 10, 2026

Code Professor Uploader ("the tool") is a private tool used only by the owner of The Code Professor YouTube channel to publish that channel's own videos. It has no other users.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

What data the tool accesses

With the channel owner's permission (Google OAuth, scope https://www.googleapis.com/auth/youtube), the tool accesses the owner's YouTube channel in order to:

  • upload the owner's own video files and thumbnail images;
  • set video titles, descriptions, tags, categories, privacy and scheduled publish times;
  • create playlists and add the owner's videos to them;
  • read the channel's own video and playlist lists to avoid duplicates.

It does not access any other user's data, comments, viewer information, analytics, or any data outside the owner's channel. The tool does not place cookies or other tracking technology on any device.

How data is used, stored and shared

Data is used only to perform the publishing actions above. OAuth credentials are kept in the owner's private environment and are never shared. The only API data the tool keeps is a private release checklist recording each uploaded video's ID and scheduled date. The tool does not sell, share or transfer data to any third party and does not use data for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

Stored video IDs are kept only while needed to manage the channel's release schedule and are refreshed or deleted at least every 30 days, in line with the YouTube API Services Developer Policies. The channel owner can delete all stored data at any time by deleting the release checklist and the stored OAuth credentials; doing so removes every piece of data the tool holds.

Revoking access

Access can be revoked at any time at Google security settings (third-party access). After revocation the tool can no longer access the channel, and any stored data is deleted within 7 days.
