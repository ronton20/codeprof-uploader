Code Professor Uploader

A private publishing tool for The Code Professor YouTube channel.

The channel owner uses it to upload their own short lesson videos to their own channel through the YouTube Data API: setting titles, descriptions, tags, thumbnails and playlists, and scheduling release times. It has no other users and offers no public sign-up.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
